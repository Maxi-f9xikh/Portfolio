5. Plugins und Tools

Google Fonts

Diese Seite nutzt zur einheitlichen Darstellung von Schriftarten Google Fonts, die von Google bereitgestellt werden. Beim Aufruf einer Seite lädt Ihr Browser die benötigten Fonts in ihren Browsercache. Zu diesem Zweck muss der von Ihnen verwendete Browser Verbindung zu den Servern von Google aufnehmen. Weitere Informationen zu Google Fonts finden Sie unter https://developers.google.com/fonts/faq und in der Datenschutzerklärung von Google: https://policies.google.com/privacy?hl=de.

GitHub Aktivitätschart

Auf der Seite „Über mich" wird ein Bild des Dienstes ghchart.rshah.org eingebunden, das die öffentliche GitHub-Aktivität darstellt. Beim Laden des Bildes wird Ihre IP-Adresse an den Anbieter übermittelt. Es werden keine weiteren personenbezogenen Daten gespeichert oder verarbeitet.

EmailJS

Das Kontaktformular nutzt EmailJS (emailjs.com) zum Versand von Nachrichten. Beim Absenden werden Name, E-Mail-Adresse und Nachrichteninhalt an die Server von EmailJS übermittelt. Weitere Informationen: EmailJS Datenschutzerklärung.

CurseForge API

Diese Website ruft über die CurseForge API (api.curseforge.com, Overwolf Ltd.) öffentlich verfügbare Download-Statistiken für Minecraft-Mods ab. Dabei wird Ihre IP-Adresse an die Server von Overwolf übermittelt. Es werden keine personenbezogenen Daten gespeichert. Weitere Informationen: Overwolf Datenschutzerklärung.
